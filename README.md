# Stock Management System
A desktop stock management application developed using C# and .NET. Uses a relational SQL database to manage product and stock records and includes functionality for user accounts, stock management and reporting.
## Technologies used:
- C#
- .NET
- Windows Forms
- SQL
- Visual Studio
## Features
- User registration and login
- Password reset functionality
- Product management
- SQL database integration
- Reporting
